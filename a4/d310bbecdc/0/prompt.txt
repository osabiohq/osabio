## Summary

Add support for [ai-sdk-provider-claude-code](https://github.com/ben-vargas/ai-sdk-provider-claude-code) as an agent provider alongside OpenRouter and Ollama. This lets people run Brain's native agents through their existing Claude subscription via locally installed Claude Code — no separate API keys or provider accounts needed.

## Why This Matters

Today, running Brain requires either an OpenRouter API key or a local Ollama setup. Most people building with AI agents already have a Claude subscription with Claude Code installed. This provider lets them reuse those existing credentials instead of paying for a separate inference provider.

The provider wraps `@anthropic-ai/claude-agent-sdk` into Vercel AI SDK's `streamText()` / `generateObject()` / `tool()` interfaces — the same abstractions Brain already uses — so it slots in with minimal changes.

## Current Architecture (Why This Is Feasible)

Brain's model layer already supports provider swapping:

- Model instantiation is a factory in `runtime/dependencies.ts` that switches between OpenRouter and Ollama based on `INFERENCE_PROVIDER` config
- Agent loops use `streamText()`, `ToolLoopAgent`, `generateObject()` — all Vercel AI SDK interfaces that the provider implements
- Tool definitions are Zod schemas — provider-agnostic
- Adding a third provider factory is the same pattern as the existing two

## Proposed Design

### 1. Add provider factory

Extend `runtime/dependencies.ts`:

```typescript
function createClaudeCodeModels(config: ServerConfig) {
  const { claudeCode } = await import('ai-sdk-provider-claude-code');
  return {
    chatAgentModel: claudeCode('sonnet'),
    extractionModel: claudeCode('haiku'),
    pmAgentModel: claudeCode('haiku'),
    // ...
  };
}
```

### 2. Configuration

```env
INFERENCE_PROVIDER=claude-code
```

No API keys needed — the provider uses the locally installed Claude Code CLI and its existing authentication (`claude auth login`).

### 3. Provider-specific options (optional)

```env
CLAUDE_CODE_EFFORT=high           # low | medium | high | max
CLAUDE_CODE_MAX_BUDGET_USD=1.00   # per-invocation cost cap (optional)
```

**In scope:**
- Provider factory for `ai-sdk-provider-claude-code` in `dependencies.ts`
